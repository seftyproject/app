Demo con Expo Go

Preparare e avviare la demo Sefty con Expo Go.

Istruzioni riassuntive

Per preparare e avviare la demo seguire GUIDAFACILE.md.

La procedura usa un computer Windows o Mac con Docker e Node.js e telefoni iPhone/Android con Expo Go. I telefoni possono usare reti diverse. Il computer deve rimanere acceso e connesso.

Prima configurazione

  1. Installare Node.js 24 LTS, Docker Desktop ed Expo Go compatibile con SDK 57.
  2. Creare un account Expo dedicato a Sefty.
  3. Aprire un terminale nella cartella DemoSefty ed eseguire npm run demo:login.
  4. Accedere allo stesso account Expo in Expo Go su tutti i telefoni.

Gli account usati dentro Sefty devono essere diversi per provare contatti, SOS e gruppi. Sono indipendenti dall'account Expo.

Comandi

Da DemoSefty, con Docker avviato:

npm run demo

Scansionare il QR corrente con i telefoni e mantenere Sefty in primo piano.

Comando Funzione
npm run demo:login Installare le dipendenze mancanti e accedere all'account Expo
npm run demo:account Mostrare l'account Expo del computer
npm run demo Controllare l'account, avviare servizi e tunnel, generare il QR
npm run demo:check Controllare backend e tunnel mentre la demo è attiva
npm run demo:stop Fermare i servizi Docker conservando il database

Per terminare, premere Ctrl+C nel terminale della demo e poi eseguire npm run demo:stop. Su Windows, se PowerShell blocca npm.ps1, usare npm.cmd al posto di npm.

Dati e limiti

Il database persiste sul computer che esegue Docker. Copiare il progetto su un'altra macchina non trasferisce gli account Sefty. Non eliminare il volume del database e non sovrascrivere il file .env di un'installazione esistente.

La demo usa GPS e comunicazioni in primo piano. Push remote ad app chiusa, GPS in background e hardware Bluetooth non sono inclusi nel collaudo. Il timer di rientro è eseguito sul telefono. Il recupero password non invia email reali. La guida contiene la sequenza da provare prima della presentazione.
